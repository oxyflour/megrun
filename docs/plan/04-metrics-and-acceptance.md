# 指标、误差预算与验收

返回 [计划提纲](accuracy-study.md)。本文件为首轮验收目标的唯一数值定义来源。阈值是本项目的初始工程目标，不是既有结果或行业标准；在正式运行前以配置文件冻结。修改目标应产生新的计划/配置版本，保留原目标下的通过与失败状态。

## 1. 比较前置条件

- 双方几何、材料和激励通过输入审计，场坐标、单位和点顺序一致。
- Maxwell 正常完成且通过局部输出、网格和外边界检查；当前求解器通过真实残差、独立复算及原生算子检查。
- 点集和区域在计算前定义；全部测点保留，无 NaN/Inf。
- 隔磁增量使用经过完整网格核对且逐级细化的成对参考。

不满足前置条件时状态为 `invalid` 或 `reference_unresolved`，不能把结果列为“误差超标但已完成有效验证”。

## 2. 总场指标

记第 i 个点参考场为 `B_ref_i`，当前求解器场为 `B_test_i`，`e_i=B_test_i-B_ref_i`。场单位统一为 T，表格可另显示 mT 或 μT。

```text
E2       = sqrt(sum_i ||e_i||^2 / sum_i ||B_ref_i||^2)
RMS      = sqrt(mean_i ||e_i||^2)
Max      = max_i ||e_i||
RefRMS   = sqrt(mean_i ||B_ref_i||^2)
```

保留 Bx、By、Bz 的逐点差、各分量 RMS 和向量误差分位数。上述 RMS 是向量误差，不是三个分量样本混合后的 RMS。E2 不是逐点百分比的平均值。

主验收对每个预定义区域分别使用等权采样，并报告整体等权结果。若另使用面积/体积权重，单独标明权重和结果，不替换主指标。增加某一区域的测点数量不能改变其他区域的验收结果。

## 3. 初始目标

`B_abs=10 μT=1e-5 T`；`Delta_abs=10 μT`。场分辨率目标是数值对齐要求，不来源于某款霍尔器件的数据手册。

| 用例/指标 | 首轮通过目标 |
| --- | --- |
| C00 固定均匀磁化 | Maxwell 和当前求解器分别相对独立解析参考，区域 E2 ≤ 0.1% |
| C01 回弹永磁、C02 线性软磁 | 区域 E2 ≤ 0.5% |
| C03 多曲线非线性软磁 | 区域 E2 ≤ 1% |
| C04–C06 完整模型总场 | 整体及每个关键区域 E2 ≤ 1% |
| C04–C06 关键场点 | 每点 `||e|| ≤ B_abs + 0.01*||B_ref||` |
| 霍尔轴向场 | 每个探针 `|Bs_test-Bs_ref| ≤ B_abs + 0.01*|Bs_ref|` |
| 隔磁增量 | 每个区域的 Delta B 相对 L2 ≤ 5%，低幅值例外见下一节 |
| 霍尔隔磁增量 | 每个探针 `|DeltaBs_test-DeltaBs_ref| ≤ Delta_abs + 0.05*|DeltaBs_ref|` |
| 当前求解器本构 | 程序实际归一化真实残差及独立复算均 ≤ 1e-8 |

关键场点集合在 M0 冻结，至少包含全部霍尔点、片两侧间隙点和指定近场点。其他点同样保留 Max 与最差点坐标，不能因不属于关键点就隐藏局部误差。C00–C03 的全部测试点采用对应相对系数 `r=0.001/0.005/0.01` 和相同 `B_abs` 的混合点误差检查。

## 4. 近零场的确定性处理

对某区域的相对目标 r，若 `RefRMS >= B_abs/r`，执行对应 E2 阈值；否则 E2 仅作描述，采用 `RMS <= B_abs + r*RefRMS` 判定。关键单点仍执行混合容差。这个切换规则在运行前固定，不按结果临时选择更宽松指标。

例如 C04–C06 的 r=1%，区域 `RefRMS<1 mT` 时转用上述绝对/相对混合 RMS。完全零参考场不计算相对百分比。

定义单点归一化误差：

```text
rho_B_i = ||B_test_i-B_ref_i|| / (B_abs + r*||B_ref_i||)
rho_H_j = |Bs_test_j-Bs_ref_j| / (B_abs + 0.01*|Bs_ref_j|)
```

关键点或霍尔点各自要求最大 rho 不超过 1。

## 5. 隔磁增量

对每个求解器分别计算：

```text
Delta B = B_with_shield - B_mu1_control
e_delta = Delta B_test - Delta B_ref
E2_delta = sqrt(sum ||e_delta||^2 / sum ||Delta B_ref||^2)
```

同时报告 Delta B 的参考 RMS、向量绝对 RMS 差、最大差和逐点三个分量，不能只报告相对百分比。先做有符号的矢量差，不能使用 `|B_with|-|B_control|` 代替 Delta B。

区域 `RefRMS_delta >= Delta_abs/0.05 = 0.2 mT` 时，要求 `E2_delta <= 5%`；更小时采用 `RMS_delta <= Delta_abs + 0.05*RefRMS_delta`，相对指标仅作描述。霍尔增量始终采用表中逐探针混合容差。

总场通过不意味着隔磁增量通过。三种尺寸分别判定；不能把 0.10 mm 组的参考诊断推广到其他尺寸。双模组都有磁源时，隔磁增量也不能直接称为某一单独磁源的串扰衰减率。

## 6. 收敛变化预算

对同一模型的两个细化等级，使用同点差替代上式的 `e`，参考幅值取最终更细等级，并采用相同低场规则。

- Maxwell 网格、空气域及非线性容差变化：每类变化均不超过对应最终误差预算的 20%。
- 当前求解器磁性网格、积分规则及迭代容差变化：每类变化均不超过对应最终预算的 20%。
- 原生/CUDA K 路线差：不超过对应最终预算的 5%。
- 同时检查总场、每个区域、霍尔投影和隔磁增量，不能仅对整体强场 E2 验证稳定性。

高幅值区域对应的总场稳定性目标是 `0.2*r`，隔磁增量为 1%；混合点误差目标为 `rho_change <= 0.2`。计算路线差相应使用 `0.05*r` 和 `rho_change <= 0.05`。

这些变化是可观测稳定性证据，不应简单相加后声称得到严格误差界。最终同时细化的组合结果还需复核，正式跨求解器误差直接按原始场差计算，不能先扣除估计的参考误差再报通过。

## 7. 验收状态

| 状态 | 含义 |
| --- | --- |
| `planned` | 尚未执行 |
| `running` | 计算或审计中 |
| `invalid` | 输入、坐标、材料、非有限场或算子检查不合格 |
| `reference_unresolved` | Maxwell 参考尚未达到场与边界稳定性要求 |
| `solver_unconverged` | 当前求解器本构未收敛 |
| `discretization_unresolved` | 方程已收敛，但网格/积分场变化仍未达要求 |
| `accuracy_failed` | 双方有效且已充分收敛，跨求解器场差超标 |
| `passed` | 该状态全部适用前置条件与指标达标 |

总验收要求所有必需用例及其冻结状态均为 `passed`，包括 C05 和 C06 的三种隔磁片、所有关键区域及霍尔投影。部分通过只能报告明确的局部适用范围，不能宣布整体目标完成。

## 8. 已有结果在新目标下的位置

历史完整模型约 3.66%–4.16% 的总场差尚未达到这里的 1% 目标；0.10 mm 差分诊断约 9.08%，也未达到 5% 的增量目标，且其完整高阶网格与差分收敛检查仍不齐全。旧报告并未承诺这些新阈值，保留原结论即可。

C05 旧加密结果归为 `solver_unconverged`，而不是 `accuracy_failed`。应先补齐有效解和独立收敛证据，再判断当前离散是否能达到新目标。
