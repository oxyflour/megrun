日期：2026-11-07。状态：计划，尚未执行本轮验证。

## 当前起点

- 3 mm 双模组、零线圈电流，无片时 485 点 B 向量相对 L2 差为 **3.6551%**。
- 三种隔磁片在共同的 566 点上，总场相对 L2 差为 **3.7492%、4.1559%、3.8782%**；同一组 566 点的无片基线为 **3.8730%**。
- 只有 0.10 mm 隔磁片有额外固定 Maxwell 角点网格的差分诊断：增量场相对 L2 差 **9.0781%**，绝对 RMS 差 **0.136167 mT**；二次边中节点未完全核对，尚不能作为严格差分误差界。
- 0.20 mm 中间尺寸的面内加密试验在 24000 步后残差为 **2.1528e-8**，没有通过 `1e-8` 验收，不能据此宣称网格收敛。厚度方向收敛还未完成。

## 阶段与交付

| 阶段 | 主要任务 | 完成条件 |

| M0：冻结共同问题 | 确认材料、几何、零电流、测点、版本和验收配置；盘点本地 AEDT 参考工程 | 输入及哈希清单齐全，正式计算前冻结阈值 |

| M2：完整无片模型 | 执行 C04，分别建立 Maxwell 与当前求解器的收敛序列 | 总场和关键区域通过目标，参考解及求解器自身变化受控 |
| M3：隔磁片与霍尔场 | 执行 C05–C06，完成三种尺寸、厚度/面内细化、同网格有片/无片差分 | 总场、霍尔投影和隔磁增量均通过目标 |
| M4：形成结论 | 汇总误差来源、收敛序列和失败记录，限定已验证范围 | 产物可复核；每个必需用例给出明确状态 |

阶段按 M0 → M1 → M2 → M3 → M4 推进。某阶段失败时，先定位参考解、本构、离散或迭代问题，再继续依赖该结果的阶段。

## 首轮验收方向

- 完整模型的总场向量相对 L2 差目标为 **1%**，每个预先定义的关键区域也分别检查。
- 霍尔轴向场及关键单点采用 **10 μT + 1% × 参考场幅值** 的混合容差。
- 隔磁增量相对 L2 差目标为 **5%**；近零增量改用预先定义的绝对误差判据。
- Maxwell 参考解、磁性网格与积分细化后的场变化，各自控制在对应误差预算的 **20%** 内。
- 当前求解器真实本构残差及独立复算均要求 **≤1e-8**。

以上是本计划提出的初始数值目标，不是现有能力声明或行业标准。计算前写入验收配置；不能根据计算结果事后放宽阈值。完整定义及低场处理见 [指标与验收](04-metrics-and-acceptance.md)。
